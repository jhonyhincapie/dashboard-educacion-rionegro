PASOS PARA PUBLICAR EN NETLIFY
================================================================================

OPCION 1: Drag & Drop (ultra rapido)
  1. Ir a https://app.netlify.com/drop
  2. Arrastrar carpeta "publicar/" al navegador
  3. Esperar a que suba
  4. ¡Listo! Se genera URL automaticamente

OPCION 2: GitHub + Netlify (recomendado, actualiza automatico)
  1. Crear repositorio en https://github.com/new
  2. Push de la carpeta "publicar/" a GitHub
  3. Conectar GitHub a Netlify (New site from Git)
  4. Elegir "publicar" como directorio de publicacion
  5. Deploy

Ver instrucciones detalladas en: NETLIFY_DEPLOY.md
